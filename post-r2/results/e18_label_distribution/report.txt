T2  DOES LABEL ENTROPY PREDICT WITNESS DISAGREEMENT? (e11's open prediction)
==============================================================================
  e11 measured sampling-noise SE against the same target and got rho +0.052, p 0.12 --
  null. Its conclusion was that the dominant error is the crop label, not pixel count.
  That conclusion predicts THIS test comes out positive. It is falsifiable and this
  is the falsification attempt.

  entropy quintile         n  mean entropy  mean |rank gap|
  Q1 (certain)          192         0.373           0.3385
  Q2                    191         0.758           0.2939
  Q3                    191         0.866           0.2857
  Q4                    191         0.922           0.2902
  Q5 (uncertain)        191         0.966           0.2964

  rho(label entropy, |rank gap| WITHIN crop)     = -0.021  p = 0.516

  DESIGN FLAW IN THE ABOVE, and the variant that fixes it. Both ranks are taken
  within the SAME crop cohort, so if a farm's label is wrong it is ranked against the
  wrong cohort on BOTH sides and the error largely cancels. That makes the test
  under-powered by construction. Re-running with GLOBAL ranks, where a label error
  cannot cancel:
  rho(label entropy, |rank gap| GLOBAL)          = +0.033  p = 0.311
  e11's sampling-SE result on the same target        = +0.052   p = 0.12

  NULL: e11's inference is NOT confirmed. If neither sampling noise nor label
  entropy predicts witness disagreement, the dominant error is in neither, and
  D-2's interval would be honest about the wrong quantity.

T5  CONTROL -- does a CORRUPTED posterior score the same?
==============================================================================
  sharpened (T=0.5)     mean p 0.619   rho(p, backed) +0.217  p = 1.25e-11
  as shipped (T=1)      mean p 0.470   rho(p, backed) +0.206  p = 1.33e-10
  flattened (T=3)       mean p 0.303   rho(p, backed) +0.193  p = 1.72e-09
  uniform               mean p 0.200   rho(p, backed) +nan  p = nan

  The T=1 row MUST reproduce T1's pooled rho exactly -- that is what makes this a
  control rather than a second measurement, and an earlier version of this script
  failed it (positional indexing into a merge that had dropped 10 farms).
  Temperature scaling barely moves rho because it leaves each farm's ARGMAX alone;
  it shifts the ordering of p_assigned only slightly, since renormalising depends on
  the whole vector. So rho is a statement about RANKING and says nothing about
  whether the LEVELS are calibrated -- which T1's +28.7pp gap in Q1 already denies.
  The uniform row is the true null: no ordering left to correlate.
